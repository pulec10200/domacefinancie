# Release process

Run npm test, npm run typecheck, npm run lint, npm run build and source Electron E2E. Bundle OCR assets with npm run setup:ocr. scripts/build-linux.sh and scripts/build-windows.ps1 validate/build native candidates; output is release/. node scripts/checksums.mjs generates SHA256SUMS.txt. Shell/PowerShell checksum verification scripts are provided.

The build generates production dependency notices from installed pinned packages, preserves Electron's LICENSE/Chromium notices and bundles OCR's Apache license. Some native transitive licensing and the missing full MIT text in upstream tr46@0.0.3 warrant owner review before commercial redistribution; do not describe this bundle as a complete legal audit. No application license has been granted on the owner's behalf (UNLICENSED).

CI uses read-only repository permissions and --publish never. It runs unit/integration, typecheck/lint/build, source E2E, native packaging, exact packaged-executable E2E, then actual .deb/NSIS installation and installed-executable E2E. Linux installed tests run without external networking. Tests cover OCR/confirmation, watched invoice/reminder/restart and verified GUI restore. Checksums/installers/notices are uploaded as Actions artifacts. The workflow does not silently create a GitHub release or sign software.

Current builds are unsigned release candidates. Windows signing requires owner-controlled certificate/trusted signing configuration supplied through protected secrets; never commit certificates/passwords or claim a signature without verifying it. Broader Windows desktop/Linux distribution/hardware and AppImage FUSE QA remain separate release-owner acceptance. Back up before real upgrades; the database migration test covers previous-schema preservation, not every installer/OS upgrade path. See VERIFICATION.md for executed evidence and remaining limits.
