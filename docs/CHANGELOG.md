# Changelog

## 1.0.0-rc.1 — 2026-11-13

Integrated finance, documents/AI and automation in one desktop product. Added schema 3 with automatic pre-migration SQLite safety snapshots; assets, contracts/insurance, categories and hierarchical budgets; account/transaction editing, reversible archiving/voiding; rule changes/exceptions, expected income and invoice estimate matching. Added provenance/correction history, structured text proposals, receipt items, original previews, PDF QR, retry/cancel/progress and separate document processing process. Added five optional AI transports, OS-key encryption, consent routing/fallback, usage/budgets and offline mocked tests. Added configurable reminders, tray/login startup, secret-free export, external data relocation and expanded backup/restore tests. Added source, packaged and installed workflow checks, dependency notices and Slovak first-use documentation.

This release is unsigned. Live paid AI requests and automatic authorized eKasa access are not claimed; eKasa uses the documented manual verification and OCR alternative.
